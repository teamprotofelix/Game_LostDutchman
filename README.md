# 금광을 찾아서 · LOST DUTCHMAN'S GOLD HD EDITION 2.0

**Chrome에서 실행 가능한 독립 제작 HTML5 / JavaScript 서부 탐험 게임.** 원작 DOS 게임의 자유도와 탐광 모험에서 영감을 얻은 비공식 팬 리메이크입니다. 원작 ROM/코드·음원은 포함하지 않았습니다.

## 실행

1. ZIP 전체 압축 해제
2. `index.html`을 Google Chrome에서 열기. 일반적인 Chrome에서는 별도 서버나 인터넷 연결이 필요하지 않습니다.
3. GitHub Pages에 배포한다면 압축 해제된 **폴더 내용**을 저장소 루트에 업로드하고 Pages의 main/(root)로 게시합니다.

## 조작

- 방향키 / WASD: 캐릭터 이동
- E 또는 Space: 상호작용 / 채굴·사금 채취 타이밍 / 전투
- 1–4: 화면 아래 행동 버튼
- I: 가방, M: 탐험 지도, J: 탐험 수첩, F6: 저장, ESC: 뒤로
- 모바일: 화면의 방향 패드와 행동 버튼, 또는 사막 지도를 터치해 목적지 지정

## 게임 내용

- 1896년 애리조나 골드필드 중심가: 살롱 / 잡화점 / 은행 / 시금소 / 마구간 / 신문사 / 보안관 / 의사
- 104개 갱도 입구로 이어지는 넓은 사막 여행. 갱도는 3층 공통 구조의 절차적 이벤트 탐광입니다.
- 강의 사금·낚시 타이밍 게임, 동굴 광석 채굴, 금 감정 후 현금화
- 수분 / 식량 / 체력 / 피로 / 더위 / 날씨 / 낮과 밤 변화
- 대퍼 댄 포커, 수배범, 야생동물, 6개 전설의 지도 단서, 최종 금광 발견 후 등록
- 브라우저 localStorage를 사용하는 자동 저장 및 이어하기

## HD Edition 2.0 그래픽 업그레이드

- 별도 AI 생성 서부 마을 원화를 1920×1080 WebP로 통합, 타이틀 아트 로고 교체
- 강·광산·살롱·야영지·금광 장면 1920×1080 아트 편집 / 복원
- 2,840×1,930 실제 월드 지형 텍스처를 카메라 위치에 따라 스크롤하도록 수정
- 탐광인 스프라이트 8열×6행, NPC 8열×4행, 야생동물 8열×4행. 256×320 픽셀 셀을 가진 WebP 애니메이션 시트
- 사금 접시·곡괭이·랜턴 등의 WebP 아이콘 아틀라스, 캐릭터 초상, 금색·가죽·목재 느낌 UI 개선
- 외부 CDN, 프레임워크, 외부 폰트 의존성 없음. 생성된 개별 WebP를 압축 파일에 포함

## 저장 및 업데이트

기존 1.0의 `goldfield_remastered_v1` 저장 키를 유지하여 동일 출처(origin)에서 이전 저장 데이터를 이어갈 수 있도록 했습니다. 다만 브라우저 origin이 바뀌면 `localStorage` 저장 내용은 공유되지 않습니다. `file://`에서의 저장 정책은 브라우저 설정에 따라 달라질 수 있습니다.
